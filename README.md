# KroustyGames

# Projet Vue.js + Node.js + PostgreSQL

## Lancement du projet

Le rendu est prévu pour être lancé avec une seule commande :

```bash
docker compose up --build
```

Services exposés :
- Frontend: http://127.0.0.1:8080
- Backend: http://127.0.0.1:5001
- PostgreSQL: 127.0.0.1:5441

## Installation

1. Clonez ce dépôt.
2. Assurez-vous d'avoir Docker installé.
3. Lancez la commande suivante pour démarrer les services :
   ```bash
   docker-compose up
